**做法**
1. **抽出有配对约束的区块**（通常 2×2 或 3×3 stem），设区块长度 ℓ。
2. **状态定义**：S[k][c] = 位置 k 配对方案 c (16 种 WC/HG/GU) 的最大平均对数似然 ∑ log pᵢ.
3. **转移**：S[k+1][c′] = max_{c} S[k][c] + log p_{k+1}(c′) + P(c,c′) ，其中 P 为邻位配对合法性（类似碱基柱 stack）。
4. 回溯得到概率最高且满足配对的子序列，替换原序列。
    
算法复杂度 O(ℓ·16²)，可在毫秒级跑完，等价于给 Teacher 输出做一次 **基于配对物理先验的后处理**——不重新训练就解决配对冲突。

 “α-ζ, χ” 角互相关，加噪怎么保证合法？

**关键**：不要在每个角上独立高斯。应采用 **联合分布采样**。
1. **Suite-level rotamer库**：46 离散构象 (η,θ) 或全七角 “suite” 分类，覆盖 > 90 % 天然 RNA 背景。[PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC2248255/?utm_source=chatgpt.com)
    **采样流程**
    取原骨架对应 suite label s₀；
    按 p(s)|context（helical/loop）抽 1-2 备用 rotamer；
    rotamer → 给出 7 角冗余矢量 (sin,cos)；
    **inverse kinematics** 解回原子，对 P–P RMSD 做 0.5–1 Å 约束；
    简单 OpenMM 20 步梯度松弛（保持键长角）。
    这样采样出的扰动 **天然保角相关**，不会出现物理冲突，也仍兼容原 backbone 全局位置。


动态流程里“没有二级结构”怎么办？
- 你**不必**提前知道完整 2D 架构；Teacher/Student 直接基于 3D 微环境预测序列。
- 如果你想把 **stem-loop 先验** 加进去，又缺 2D：
    1. 用 **η–θ 伪扭转角** 聚类估算邻接矩阵，对 |Δr|<8 Å 且 |Δη|<30° 设为可能 base-pair；
    2. 运行 McCaskill-style DP 得到配对概率 pₚ(i,j)；
    3. 把 pₚ > 0.7 的 (i,j) 送进动态规划修补步骤（§2）。

这相当于让模型自己“软推断”二级结构——准确度往往 > 80 %。
