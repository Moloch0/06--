Ouroboros的做法是先预训练一个GNN编码器，有两个预训练任务，MFS和CSS，然后分别训练两个，结构解码器和性质解码器，因此它生成特性可能弱一些？

具体来说，分子有多个构象，   同一分子在 3D 中可以摆出不同姿势（构象）。 有时仅靠 2D 连接信息，还不足以解释药效差异。定义“构象空间相似度” (CSS)，分子的 **全构象集合 + 药效基团分布(Pharmacophore)** 转成一个描述符。把“分子 A 与 B 的 CSS”当成“投影头”(projection head)做对比学习：若 CSS 高 → 两分子正样本；CSS 低 → 负样本，比传统自监督更强调 3D 化学语义。
